# RookNews

Offline-first, on-device AI news curator for **Android & iOS**.

## Features

- **Offline-first** — all AI runs on-device via llama.cpp
- **Multi-source RSS** — curate articles from any RSS/Atom feed
- **AI briefings** — daily digests generated by your local model
- **Bias analysis** — see how articles lean across the political spectrum
- **Deep research** — multi-turn AI research on any topic
- **Privacy-first** — no telemetry, no analytics, no account required

## Architecture

```
composeApp/               ← UI, navigation, DI wiring (Android + shared Compose)
core/
├── domain/               ← Pure Kotlin: models, repository interfaces, use cases
├── data/                 ← Repositories, SQLDelight, Ktor, RSS parsing
└── ai/                   ← InferenceProvider, AI pipeline, model catalog
```

**Clean Architecture**: `composeApp` → `core:domain` (interfaces) → `core:data` + `core:ai` (implementations)

## Tech Stack

| Concern | Choice |
|---------|--------|
| Language | Kotlin 2.1.0 |
| UI | Compose Multiplatform 1.7.3 |
| Navigation | Compose ViewModel (5-tab bottom nav) |
| State | MVVM + StateFlow + `AiStreamState` |
| DI | Koin 4.0.1 |
| Database | SQLDelight 2.0.1 |
| Network | Ktor 3.0.1 |
| On-device AI | llama.cpp (GGUF Gemma 4) |
| Cloud fallback | Google Gemini API (Pro tier) |

## Platforms

- **Android**: minSdk 24, targetSdk 35
- **iOS**: deployment target 14.1

## Getting Started

```bash
# Build and run on Android
./gradlew :composeApp:assembleDebug

# iOS — open iosApp/iosApp.xcodeproj in Xcode
```
